Episode 1 Misteri Brankas Token JWT & Pembobol Kunci
File: Day10/middlewares/jwt.go
📖 Cerita Kasus:

Admin Toko bernama Budi berhasil login. Sistem tidak menyimpan sesi di memori server, melainkan memberikan Budi sebuah token JWT. Token ini dibagi menjadi 3 bagian: Header (algoritma), Payload (data user), dan Signature (tanda tangan rahasia). Seorang penyusup mencoba memalsukan token dengan kunci rahasianya sendiri. Bagaimana server mendeteksinya?

  }
}

Episode 2 Sang Alkemis Password (Plaintext vs Bcrypt)
File: handlers/user-handler.go:51 vs seeders/seeder-user.go:12
📖 Cerita Kasus:

Admin membuat user baru lewat Form Web (`/admin/users/create`). Namun setelah dibuat, user tersebut selalu gagal login! Ternyata, form web menyimpan password mentah (contoh: kopi123), sedangkan fungsi Login() selalu mencocokkan password menggunakan bcrypt.CompareHashAndPassword. Karena di database bukan hash Bcrypt, login otomatis ditolak!

Episode 5 Kutukan Amnesia Database (Seeder Truncate)
File: databases/seeders/seeder-products.go:19
📖 Cerita Kasus:

Pernahkah Anda heran mengapa setiap kali server dimatikan lalu dijalankan lagi, produk-produk baru yang Anda buat mendadak lenyap? Penyebabnya adalah baris configs.DB.Exec("TRUNCATE TABLE products") di dalam seeder. Seeder yang baik seharusnya bersifat Idempoten: mengecek apakah tabel sudah memiliki data terlebih dahulu sebelum memasukkan data default!

Perbandingan Logika Seeder:
❌ Cara Lama (Menyebabkan Data Hilang) 
configs.DB.Exec("TRUNCATE TABLE products")
configs.DB.Create(&products)
// Menghapus semua data admin setiap restart!
✅ Cara Benar (Aman & Idempoten) 
var count int64
configs.DB.Model(&models.Product{}).Count(&count)
if count == 0 {
    configs.DB.Create(&products)
} // Lewati jika sudah ada data!
